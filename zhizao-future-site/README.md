# 智造未来 · 材料 × 人工器官与组织

一个面向课堂小组展示的学术专题网站。以科技蓝为主色，围绕“材料如何与细胞、组织、器官对话”展开，从问题、材料、界面、证据、制造，最终回到课堂收获与伦理反思。

## 如何打开

- **最简单**：双击 `index.html`，用 Chrome / Edge / Safari 打开。
- **推荐**：在本目录启动一个本地服务器，然后访问 `http://127.0.0.1:8765/`。

```powershell
python -m http.server 8765
```

网站没有外部字体、框架或 CDN 依赖，离线也能正常阅读。

## 课堂展示

点击右上角或页脚的「演示模式」，进入 8 页课堂演示：

1. 封面：智造未来
2. 问题：器官短缺与被延长的等待
3. 材料：四种材料家族
4. 界面：材料如何向细胞传递信号
5. 图谱：六类器官的材料方案
6. 证据：四个案例与 TRL 阶梯
7. 课堂：我们真正带走了什么
8. 结尾：从智造到善治

演示中可用：

- `←` / `→` 或 `PageUp` / `PageDown` 翻页
- `Home` / `End` 跳到首尾
- `Esc` 退出（全屏状态下先退出全屏，再按一次退出演示）
- 右上角全屏按钮

## 页面中的三个互动

- **材料指纹**：切换高分子、水凝胶、生物陶瓷、金属与复合，雷达图会显示相对设计倾向。分值为教学示意，不是实测数据。
- **器官—材料匹配器**：选择皮肤、血管、心肌、角膜、骨或肝，读取功能约束、三层材料栈与证据锚点。
- **阅读进度 / 章节导航**：滚动时顶部会显示阅读进度，并高亮当前章节。

## 修改成你们小组的版本

- **小组名称**：搜索 `课程小组`，可替换为真实组名。主要位置在首页眉题、页脚和演示模式封面。
- **组员姓名 / 课程名称**：可在页脚 `footer-meta` 区域添加。
- **主色**：在 `styles.css` 顶部的 `:root` 中修改 `--blue`、`--cyan`、`--bg` 等变量即可整体换色。
- **参考文献**：在 `index.html` 的 `#references` 区域增删；正文上标使用 `href="#ref-N"`。
- **数据与案例**：建议保留现有引用与限定语。若要替换数字，请同时更新数据来源。

## 学术与图像说明

- 器官移植数据来自 WHO 2024 年通报所引用的全球器官捐献与移植观察站（GODT）2022 年数据。
- 文献条目为课程综述所用核心文献，正文上标与文末编号一一对应。
- 页面中的显微纹理均为**程序生成的示意图像**，用于表达纤维、孔隙、矿化与网络结构，不是真实实验图像。
- 雷达图是教学用相对示意；TRL 分级为课程讨论用简化，非官方评估。
- 本站仅用于课程学习与小组展示，不构成医疗建议。

## 兼容性

- 推荐最新版 Chrome / Edge / Safari。
- 支持桌面、平板与手机；在 1366×768 投影环境下，首页会自动收紧排版以保留核心数据。
- 关闭 JavaScript 后，正文仍然可见；互动图表与演示模式需要 JavaScript。
